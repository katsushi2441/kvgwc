# kvgwc — Kurage Vibe Groupware Core

**Google Workspace のアカウントでログインして使う、社内業務アプリの土台**です。

アカウント管理はゼロ（Workspaceのアカウントをそのまま使う）。追加の月額もゼロ
（今お使いのレンタルサーバーに置くだけ）。そこに、日報でも点検記録でも稟議でも、
**必要なアプリだけを足していけます**。

- **データベース不要**（JSONファイルに `flock` で書きます）
- **外部ライブラリ不要**（Composer も npm も使いません）
- **PHPが動く共有レンタルサーバーで動きます**（FTPで上げるだけ）
- **MIT License** — 商用利用・改変・再配布・再販が自由です

## Core に入っているもの

| | 中身 |
|---|---|
| **ユーザー認証** | 社員番号＋パスワード／Google Workspace／Microsoft 365 |
| **ユーザー管理** | アカウントの発行・役割・停止・権限の棚卸し |
| **社員管理** | 社員マスタ（社員番号・部署・役職・在籍状態） |
| **共有スケジュール** | 全員に公開・スマホの標準カレンダーに取り込める |

**業務アプリ（日報・点検記録・経費精算など）は Core に含まれません。**
`apps/` に定義ファイルを1枚置けば増えるので、必要なものだけを足してください。
デモには実装例を入れてあります（「別売りアプリ」の札が付いているもの）。

## アプリの増やし方

`apps/` にファイルを1枚置くだけで、メニューに出ます。登録も再起動も要りません。

```php
<?php   // apps/tenken.php — 設備点検記録
return array(
    'key'  => 'tenken',
    'name' => '設備点検記録',
    'icon' => '🔧',
    'fields' => array(
        array('key' => 'date',   'label' => '点検日', 'type' => 'date', 'required' => true),
        array('key' => 'site',   'label' => '設備',   'type' => 'select',
              'options' => array('1号機', '2号機', '受電設備')),
        array('key' => 'result', 'label' => '判定',   'type' => 'radio',
              'options' => array('良', '要観察', '不良')),
        array('key' => 'note',   'label' => '所見',   'type' => 'textarea'),
    ),
    'permissions' => array(
        'staff' => array('create' => true, 'read' => 'own',  'update' => 'own'),
        'chief' => array('create' => true, 'read' => 'dept', 'update' => 'dept'),
        'admin' => array('*' => 'all'),
    ),
);
```

入力欄も、一覧も、検索も、CSV出力も、検証も、土台が作ります。

## 社員とアカウントは別物

会社で使うので、**人事の実体（社員）**と**ログインする権利（アカウント）**を分けて持ちます。

| | 社員 | アカウント |
|---|---|---|
| 持つもの | 社員番号・氏名・カナ・**部署**・役職・入社日・退職日・内線・携帯・在籍状態 | ログインID・認証方式・**役割**・有効/無効・最終ログイン |
| 無くてよい | — | **アカウントを持たない社員がいてよい**（現場・パート） |
| 消し方 | 記録が残っていたら削除不可 → **退職**にする | 削除可（社員と過去の記録は残る） |

**部署は社員が、役割はアカウントが持ちます。**管理画面も2枚に分かれています。

- **社員マスタ** … 人を登録・更新・削除する。在籍状態を変える
- **アカウント** … いまログインできる人の一覧。役割の棚卸しと、停止・削除

アカウント一覧は**要確認のものを先頭にまとめます**（退職者のアカウントが残っている／
一度もログインしていない／90日以上ログインがない／社員に紐づいていない）。

そして**在籍状態を「退職」にすると、アカウントが有効のままでもログインできません**。
退職者のアカウント削除を忘れても締め出せるように、判断を1か所（`kv_user_compose()`）に集めています。

## 権限の考え方

役割は3つだけ（担当 / 責任者 / 管理者）。範囲は3語だけ。

| 語 | 意味 |
|---|---|
| `own` | 自分が作ったものだけ |
| `dept` | 同じ部署の人が作ったものだけ |
| `all` | 全部 |

この3語で、日報も稟議も点検記録も成立します。**判定は `kv_can()` 1か所にしかありません。**

## スマホの標準カレンダーで見える

アプリ定義に `caldav` を足すと、一覧に「📱 スマホに登録」が出ます。

```php
'caldav' => array('date'=>'date', 'start'=>'start', 'end'=>'end',
                  'title'=>'title', 'location'=>'place', 'note'=>'memo'),
```

iPhone・Android・Googleカレンダーが**そのまま購読**します（専用アプリ不要）。
購読URLは**人ごとに合言葉が違い、その人が読める範囲だけ**を配信します。

## 改造したら


緩むと社内の個人情報が別部署に漏れます。
